# EYFI RankUp

Create a single-page interactive leaderboard for the EYFI (Earn Your First Income) Challenge.

This is a design assignment for a platform targeting Indian college students. The leaderboard ranks participants by the income they have earned during the challenge.

Design goals:

youthful

energetic

competitive

motivating

modern

premium but simple

suitable for Indian college students

should feel like a real product, not a generic admin dashboard

Build only the frontend using realistic mock data. Do not create authentication, payments, database functionality, admin panels, or unnecessary pages.

The page should include:

EYFI branding/header

"EYFI Challenge" title

Short motivational subtitle

Current user's total earnings

Current user's rank

Rank movement since the previous period

Visually attractive Top 3 leaderboard

Leaderboard list/table for other participants

Clearly highlight the current user's row

Rank, participant name, and earnings for each participant

Up/down/no-change indicators

A motivational message showing how much more the user needs to earn to reach the next rank

"All Time" and "This Week" filters

Use Indian student names and realistic INR amounts.

Make the layout responsive and polished. Prioritize strong visual hierarchy, spacing, typography, usability, and a visually engaging leaderboard experience.

Do not add unnecessary features. Keep the entire experience focused on the EYFI challenge leaderboard.
